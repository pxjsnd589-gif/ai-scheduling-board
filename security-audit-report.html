📖 使用方法

① 发布前脱敏检查

每次发布前运行，检测真名/私人邮箱/电脑用户名/真人测试数据/API Key：

$ node scripts/pre-release-check.js

② 安装 pre-commit hook（提交前自动检查）

$ npm run install-hook

③ GitGuardian 配置（需手动完成一次）

  • 注册 GitGuardian 账号（个人免费）
  • 获取 API Key：dashboard → API Keys → Create
  • 添加到 GitHub：仓库 Settings → Secrets → Actions → New secret
  • 名称填 GITGUARDIAN_API_KEY，值填你的 Key

配置后，每次 Push/PR 会自动扫描密钥泄露，打 Tag 发布前会同时运行脱敏检查 + GitGuardian。
